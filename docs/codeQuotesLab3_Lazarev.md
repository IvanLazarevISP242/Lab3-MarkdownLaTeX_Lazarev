## Блоки кода
inline-код
команда `git push` отправляет отправляет зафиксированные изменения (коммиты) из вашего локального репозитория в удаленный репозиторий (например, на GitHub, GitLab или Bitbucket), делая их доступными для остальных участников команды

блок кода на python:
```python
while true:
    print("i love programming")
```

блок кода без указания языка:
```csharp
using System;

class Program
{
    static Main()
    {
        Console.WriteLine("Привет, мир!");
    }
}
```
