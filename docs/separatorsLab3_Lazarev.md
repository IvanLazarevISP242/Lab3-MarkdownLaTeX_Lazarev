Markdown — это облегчённый язык разметки, который используется для форматирования текста с помощью простых символов и знаков препинания в обычном текстовом редакторе.
---
Markdown — это легкий язык разметки, который позволяет форматировать простой текст с помощью интуитивных символов без использования сложных HTML-тегов
***
пример форматирования: заголовки
# заголовок
### заголовок
## заголовок
